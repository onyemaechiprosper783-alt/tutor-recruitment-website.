# Tutor Recruitment Website

Premium tutor recruitment application for Pinnacle Tutors Academy.

## Scope
- WAEC and JAMB teaching criteria only
- WAEC: 7:00 PM–9:00 PM
- JAMB: 9:00 PM–11:00 PM
- Both: 7:00 PM–11:00 PM
- Responsive applicant experience
- Admin-ready architecture

## Development
This repository is intentionally kept framework-light at initialization so the application stack can be added cleanly.
